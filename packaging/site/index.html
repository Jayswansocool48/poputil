PopUtil

Version @VERSION@

A control panel for Pop!_OS that finds every app on your PC, shows where it lives, and removes what you don't need without breaking anything.

Install

Paste this into a terminal. It adds PopUtil's update source, so new versions show up in the COSMIC Store.

flatpak install --user @SITE_URL@/poputil.flatpakref

Download the install fileDownload the app file

Updates

  1. New versions appear under Updates in the COSMIC Store.
  2. Or run flatpak update in a terminal.

Remove

flatpak uninstall --user io.github.Jayswansocool48.PopUtil

Your settings and anything waiting in Removed stay in ~/.local/share/poputil.
